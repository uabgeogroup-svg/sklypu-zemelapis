# GEO GROUP – sklypų darbo žemėlapis

Naujausia versija visada: **https://uabgeogroup-svg.github.io/sklypu-zemelapis/**

* Vienas HTML failas (`index.html`), duomenys imami iš viešų paslaugų (RC, geoportal.lt, NŽT, Infostatyba ir kt.).
* `version.json` – dabartinės versijos numeris; seni atsisiųsti failai pagal jį parodo, kad yra naujesnė versija.
* LiDAR reljefo įrankis (Python, veikia vartotojo kompiuteryje) šioje repozitorijoje neskelbiamas.
